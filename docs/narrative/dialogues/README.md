# Dialogues

Les dialogues se RÉDIGENT dans les fichiers de scènes (section
« Dialogues »), tant que la scène est en écriture.

Quand une scène atteint `approved`, ses dialogues sont extraits ici au
format structuré du pipeline (un fichier par scène :
`DIALOGUE_SCENE_CH01_001.yaml` — format défini dans
[technical/content_pipeline.md](../../technical/content_pipeline.md)),
puis compilés en données pour les banques de la cartouche.

Le moteur de texte étant le chantier de la phase 3, ce dossier restera
vide jusque-là : le format est contractualisé d'avance pour que le
Narrative Director écrive sans attendre le moteur.
