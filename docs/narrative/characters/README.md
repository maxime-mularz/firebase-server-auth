# Personnages

Un fichier par personnage, nommé d'après son identifiant :
`CHAR_PROF_ORION.md`. Modèle : [templates/character-template.md](../../templates/character-template.md).

Règles :

- l'identifiant `CHAR_*` est STABLE — le nom affiché peut changer, pas lui ;
- tout personnage référencé par une scène (`characters:` du front matter)
  doit avoir son fichier ici — le validateur y veille ;
- l'arc du personnage appartient au Narrative Director ; la faisabilité
  de ses apparitions (sprites, palettes) au Technical Director.

Le fichier `EXEMPLE-CHAR_PROF_ORION.md` montre le format rempli — c'est
un EXEMPLE, à remplacer par les vrais personnages.
