# Chapitres

Un fichier par chapitre : `CHAPTER_01.md`, etc.
Modèle : [templates/chapter-template.md](../../templates/chapter-template.md).

Un chapitre liste ses scènes (ordre narratif) ; chaque scène a son propre
fichier dans [scenes/](../scenes/). Le validateur vérifie que chaque
scène pointe vers un chapitre existant et que chaque chapitre a au moins
une scène.

`EXEMPLE-CHAPTER_00.md` est un EXEMPLE de format, pas un chapitre du jeu.
