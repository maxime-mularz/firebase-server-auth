# Décisions (ADR)

Toute décision structurante — technique, narrative ou de périmètre —
finit ici, numérotée, avec son contexte et ses raisons. C'est la mémoire
des « pourquoi ».

- Modèle : [ADR-000-template.md](ADR-000-template.md)
- Une décision n'est définitive que si son statut est **Accepté**
  (validation du Creative Director).
- On ne modifie pas un ADR accepté : on le REMPLACE par un nouveau qui
  le référence (statut de l'ancien : Remplacé).
